# ENV_V1 · Sensor Dashboard

## 👉 [เปิดหน้า Dashboard](https://copter36775-blip.github.io/ENV_V1/)

https://copter36775-blip.github.io/ENV_V1/

หน้าเว็บแสดงค่าจากเซนเซอร์ AHT20 + BMP280 จำนวน 4 โมดูลบน ESP32 (เฟิร์มแวร์ `sensor_web`)
มีค่าที่วัดได้ ค่าทางฟิสิกส์ที่คำนวณได้ (จุดน้ำค้าง, ความหนาแน่นอากาศ CIPM-2007 ฯลฯ) กราฟ สถิติ และ Allan deviation

| อุปกรณ์ | วิธีเชื่อมต่อ |
|---|---|
| คอมพิวเตอร์ (Chrome / Edge) | USB หรือ Bluetooth |
| Android (Chrome) | Bluetooth |
| iPhone | เปิดลิงก์ด้วยแอป [Bluefy](https://apps.apple.com/app/id1492822055) แล้วใช้ Bluetooth |

ยังไม่ได้ต่อบอร์ด: เลือก **Demo** เพื่อดูหน้าตาด้วยข้อมูลจำลอง
