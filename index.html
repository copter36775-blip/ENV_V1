ตั้งค่า

ค่า ± เริ่มต้นมาจาก datasheet (ค่า typical ไม่ใช่ผลสอบเทียบ) ถ้าสอบเทียบเซนเซอร์แล้ว ให้ใส่ความไม่แน่นอนจากใบรับรองแทน การตั้งค่าจะถูกจำไว้ในเบราว์เซอร์นี้

สูตรที่ใช้

t = อุณหภูมิ (°C) จาก AHT20, T = t + 273.15 K, RH = ความชื้นสัมพัทธ์ (%) จาก AHT20, p = ความดัน (hPa) จาก BMP280

ความดันไออิ่มตัวและความดันไอน้ำ (Magnus, Alduchov & Eskridge 1996)

e_s = 6.1094 · exp(17.625·t / (t + 243.04)) [hPa] e = (RH/100) · e_s

คลาดเคลื่อนสัมพัทธ์น้อยกว่า 0.4% ในช่วง −40 ถึง 50 °C (เหนือผิวน้ำ)

จุดน้ำค้าง (Dew point)

γ = ln(RH/100) + 17.625·t / (243.04 + t) t_d = 243.04·γ / (17.625 − γ)

อุณหภูมิที่ไอน้ำในอากาศเริ่มควบแน่น ใช้ประเมินความเสี่ยงที่จะเกิดหยดน้ำบนผิวอุปกรณ์ที่เย็นกว่าอากาศ

ความชื้นสัมบูรณ์ และอัตราส่วนผสมไอน้ำ

ρ_v = e·M_v / (R·T) = 216.674 · e / T [g/m³] w = 621.96 · e / (p − e) [g/kg อากาศแห้ง]

เอนทาลปีจำเพาะของอากาศชื้น (ASHRAE)

h = 1.006·t + (w/1000)·(2501 + 1.86·t) [kJ/kg อากาศแห้ง]

พลังงานความร้อนในอากาศ ใช้ในงานระบบปรับอากาศ

ความหนาแน่นอากาศ (CIPM-2007, Picard et al. 2008)

ρ_a = p·M_a / (Z·R·T) · [1 − x_v·(1 − M_v/M_a)] (p ใน Pa) p_sv = exp(A·T² + B·T + C + D/T) A = 1.2378847e-5 K⁻², B = −1.9121316e-2 K⁻¹, C = 33.93711047, D = −6.3431645e3 K f = 1.00062 + 3.14e-8·p + 5.6e-7·t² x_v = (RH/100) · f · p_sv / p Z = 1 − (p/T)·[a0 + a1·t + a2·t² + (b0 + b1·t)·x_v + (c0 + c1·t)·x_v²] + (p²/T²)·(d + e·x_v²) a0 = 1.58123e-6 K/Pa, a1 = −2.9331e-8 /Pa, a2 = 1.1043e-10 /(K·Pa) b0 = 5.707e-6 K/Pa, b1 = −2.051e-8 /Pa, c0 = 1.9898e-4 K/Pa, c1 = −2.376e-6 /Pa d = 1.83e-11 K²/Pa², e = −0.765e-8 K²/Pa² M_a = [28.96546 + 12.011·(x_CO2 − 0.0004)]·1e-3 kg/mol, M_v = 18.01528e-3 kg/mol, R = 8.314472 J/(mol·K)

สูตรมาตรฐานของ CIPM สำหรับแก้ผลของแรงลอยตัวของอากาศ (air buoyancy) ในงานสอบเทียบมวลและเครื่องชั่ง ใช้ได้ในช่วง 600–1100 hPa และ 15–27 °C ถ้านอกช่วงนี้หน้าเว็บจะขึ้นเครื่องหมายเตือน ความไม่แน่นอนของตัวสูตรเองเล็กมาก (ระดับ 10⁻⁵) เมื่อเทียบกับความไม่แน่นอนของเซนเซอร์ CO₂ มีผลประมาณ +0.4×10⁻⁶ ของ ρ ต่อ 1 µmol/mol ถ้าไม่ได้วัด CO₂ ควรนับเป็นแหล่งความไม่แน่นอนเพิ่ม

อุณหภูมิกระเปาะเปียก (Stull 2011)

t_w = t·atan(0.151977·√(RH + 8.313659)) + atan(t + RH) − atan(RH − 1.676331) + 0.00391838·RH^1.5·atan(0.023101·RH) − 4.686035

สูตรเชิงประจักษ์ที่ความดันระดับน้ำทะเล ใช้ได้ที่ RH 5–99% และ −20 ถึง 50 °C คลาดเคลื่อน −1 ถึง +0.65 °C

ดัชนีความร้อน (Heat index, NWS / Rothfusz 1990)

แปลง t เป็น °F (TF) แล้วคำนวณ HI = 0.5·[TF + 61 + 1.2·(TF − 68) + 0.094·RH] ก่อน ถ้าค่าเฉลี่ยของ HI กับ TF ≥ 80 °F จะใช้สมการถดถอยของ Rothfusz พร้อมค่าปรับเมื่อ RH < 13% หรือ RH > 85% แล้วแปลงกลับเป็น °C เป็นค่า "อุณหภูมิที่ร่างกายรู้สึก" คลาดเคลื่อน ±1.3 °F

ความสูงตามความดัน (Pressure altitude, ISA)

h_p = 44330.77 · [1 − (p / 1013.25)^0.190263] [m]

ความสูงในบรรยากาศมาตรฐานที่ให้ความดันเท่านี้ ค่าความดันที่ต่างกัน 0.12 hPa เท่ากับความสูงต่างกันประมาณ 1 m

สถิติ

ค่าเฉลี่ย x̄ = Σx/n SD s = √[Σ(x − x̄)² / (n − 1)] u(x̄) = s/√n แนวโน้ม b = Σ(t − t̄)(x − x̄) / Σ(t − t̄)² (ต่อชั่วโมง) E_n = |x̄_i − x̄_j| / √(U_i² + U_j²) (|E_n| ≤ 1 = สอดคล้องกันภายในความไม่แน่นอน)

u(x̄) = s/√n ถือว่าแต่ละตัวอย่างเป็นอิสระต่อกัน ซึ่งไม่จริงเมื่อค่าเปลี่ยนช้าๆ ตามสภาพห้อง จึงควรดูประกอบกับ Allan deviation

Allan deviation (แบบ overlapping)

σ²(τ) = 1 / [2·m²·(N − 2m + 1)] · Σ_j ( Σ_{i=j}^{j+m−1} (y_{i+m} − y_i) )² τ = m·τ0

ความไม่แน่นอน (GUM)

ค่า ± จาก datasheet ถือเป็นความไม่แน่นอนแบบ Type B แปลงเป็น u ตามที่ตั้งค่าไว้ ปริมาณที่คำนวณได้ใช้สัมประสิทธิ์ความไว (sensitivity coefficient) ที่หาเชิงตัวเลข แล้วรวมแบบ uc = √Σ(ci·ui)² โดยถือว่า T, RH, p ไม่สัมพันธ์กัน รายงานเป็น U = k·uc

สเปกเริ่มต้น: AHT20 ±0.3 °C, ±2 %RH (typical) · BMP280 ±1.0 hPa (950–1050 hPa, 0–40 °C), ความแม่นยำสัมพัทธ์ ±0.12 hPa · อุณหภูมิของ BMP280 ±1.0 °C
